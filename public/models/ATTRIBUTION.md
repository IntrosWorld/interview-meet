# Interviewer character and studio

Base human, topology, skin/eye/hair textures and facial shapes: `mpfb.glb` by met4citizen, created using Blender and MPFB. The upstream author explicitly releases this avatar under CC0:
https://github.com/met4citizen/TalkingHead#readme (web app asset attribution section).
Original download: https://raw.githubusercontent.com/met4citizen/TalkingHead/main/avatars/mpfb.glb

The separate TalkingHead JavaScript library was NOT copied or included. The base avatar's CC0 dedication is distinct from that library's license.

Modifications for Interview Meet: fitted charcoal garment shell, shirt and lapel materials, skin shading, pose, preview performance, studio geometry, lighting, camera and Three.js speech-event integration. The original existing Ready Player Me model in the repository is not used by this implementation.

`interviewer.glb` contains the character and facial rig. `interviewer-studio.glb` contains the set. The editable source project is `art/interviewer-studio.blend`, generated by `scripts/build-interviewer-studio.py` through Blender MCP.
